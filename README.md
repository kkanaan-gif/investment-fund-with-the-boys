# 💰 Investment Fund With the Boys

### Collaborative Investment Tracking Web Application

## 📌 Project Overview

Investment Fund With the Boys started as an idea among friends who wanted to combine their money into a shared investment fund.

The goal was to build a web application that could help the group organize their investments, monitor financial performance, and keep track of profits and losses.

This project explores how software can make collaborative investment management more organized and transparent.

##  Project Objectives

- Organize investments made through a shared fund.
- Track investment performance over time.
- Monitor profits and losses.
- Improve transparency among participating members.
- Provide a central platform for financial information.

## Technologies Used

- **Python** — Backend development
- **Flask** — Web application framework
- **SQLAlchemy** — Database integration
- **Flask-Login** — Authentication framework
- **Jinja2** — Server-side HTML templates
- **Gunicorn** — Application deployment server

## Project Motivation

The project was inspired by a real conversation between friends about pooling money for investments.

Rather than relying solely on manual calculations or spreadsheets, the idea was to create a centralized system for recording and reviewing investment performance.

##  Future Development Ideas

- Individual member contribution tracking
- Investment portfolio dashboard
- Profit and loss calculations
- Percentage ownership tracking
- Investment performance charts
- Financial reporting and summaries
